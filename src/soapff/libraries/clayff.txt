# engine clayff: soapff_cui (soapff-gui), unchanged.  Every atom gets the ClayFF type of the most similar atom of the references

# References: the 11 bulk layered minerals and their basal (0 0 1) slabs in vacuum (LAMMPS data files with the ClayFF type

#     soapff.new_library("myclay", extends="clayff");  soapff.add_reference("myclay", "mymineral.data")
# (the data file of the mineral with its ClayFF types and charges; see examples/library/ of soapff-gui).
